## 🎮 Current Research

### Personalized LLM-based Procedural Content Generation

My Master's research explores how **Large Language Models can be used to generate personalized game content** based on player characteristics.

The goal is to move from:

> **"Generate a level."**

toward:

> **"Generate a level that is appropriate for this player."**

I'm particularly interested in the intersection of:

**LLMs + PCG + Player Modeling + Reinforcement Learning + Game Design**
